一、必需性的定义：基因破坏导致致死，即为必需

核心定义。一个基因是"必需基因"，指它在该物种里被破坏（敲除、插入失活、耗竭）之后，机体或细胞无法存活/无法繁殖。 反之，破坏后个体仍可正常存活与繁殖，则为非必需。因此每一份必需性数据集，本质是一张 "破坏实验 → 是否致死" 的记录表：Y=1 表示破坏后致死，Y=0 表示破坏后仍可存活。

实验破坏 → 表型观察 → 标签： 对基因实施破坏（敲除、插入失活、CRISPR 耗竭等）→ 观察生物的存活与繁殖表型 → 致死 = 必需（1）；正常存活 = 非必需（0）。

为什么"序列"能预测"必需性"？因为基因的作用都通过它编码的蛋白质来执行：活性位点的化学反应、与其它蛋白的结合、 在膜上形成的通道、在 DNA 复制/翻译里担任的核心角色，这些职责全部写在氨基酸序列里。演化使功能上不可缺失的基因保持高度保守： 必需性越强的蛋白，序列变化的容忍度越低。所以从序列本身（组成、保守区域、理化性质、结构倾向）判断该序列所编码的蛋白是否为生存所必需， 在生物学上是成立的。我们的模型仅以序列为输入，不使用任何实验信息，输出对必需性的预测。

1.1 怎么敲除的：每种技术的分子机制与"死亡怎么被看见"

技术分子层面怎么敲死亡怎么被观察到
同源重组缺失（酵母 SGD[1]、大肠 Keio[2]与 MG1655 系统测定[3]、枯草 DEG1001[4]）带抗性标记的替换片段与染色体同源区重组，把整个编码区从基因组上物理删除，一个菌株只缺一个基因平板培养缺失株：无法生长＝致死（Y=1）；正常生长＝非必需（Y=0）
小鼠敲除（IMPC[5]、DEG[6]）受精卵或胚胎干细胞里删基因/插终止盒，繁育出纯合敲除个体纯合子胚胎不发育或出生即死＝致死；活到成体且可繁殖＝非必需
条形码插入突变库（疟虫[7]、衣藻 CLiP[8]）转座子/敲除载体随机插入打断阅读框，每个突变带唯一条形码，几千个基因并行试群体传代后给条形码测序计数：某基因的条形码从群体中消失或锐减＝携带该插入的细胞死亡＝必需
CRISPR 文库筛选（人细胞系[9][10]、弓形虫[11]）sgRNA 文库感染[12]，Cas9 切断靶基因造成移码失活，数万个基因在群体中同时被扰动培养数代后测 sgRNA 丰度：靶向某基因的 sgRNA 丰度显著下降＝携带该 sgRNA 的细胞被清除＝必需（弓形虫用 GMM 对表型分二分档）
胚胎缺陷诱变 EMB（拟南芥[13][14]）EMS 化学诱变或插入突变打坏只在种子里干活的基因种子发育到一定阶段停止/败育＝胚胎致死；种子正常饱满＝非必需
群体遗传约束（人 gnomAD[15]，非实验）不做任何敲除：统计十几万自然人群基因组里每个基因的功能失活（LoF）变异有多少某基因的 LoF 变异几乎不存在＝自然界替我们敲过无数次，携带该变异的个体无法存活＝"天然敲除致死"

1.2 为什么基因破坏导致致死即等价于必需：不可替代性原理

细胞存活所需执行的功能集合是固定的：DNA 复制、转录、翻译（蛋白合成）、能量代谢、膜完整性、细胞分裂……每一项功能都需要特定蛋白执行。 破坏一个基因是否致死，取决于其所承担的功能是否存在冗余：

敲掉基因 → 它编码的蛋白消失 → 该功能失去执行者
→ 无功能冗余（无同工蛋白、无旁路通路）→ 细胞功能停摆 → 致死 ＝ 必需（Y=1）
→ 存在冗余备份（同工酶、并行通路），或该功能本身非生存所必需 → 存活 ＝ 非必需（Y=0）

所以标签的生物学本质是：Y=1 ＝"这个蛋白承担着不可替代的功能"；Y=0 ＝"功能可替代，或该功能本身非生存必需"。 这也解释了为什么必需基因在所有物种里都是少数（我们小鼠主池正例率仅 7.3%，443/6,050）：生存清单就那么几件，大多数基因执行的是非核心功能[16-17]。

1.3 为什么"预测蛋白"就能"预测基因必需性"：功能写在序列里

基因并不直接执行功能，功能由其编码蛋白执行。序列决定结构，结构决定功能，功能决定"能不能被替代"，这条因果链的源头就是序列[18]。 而且演化将"功能不可缺失"这一信息直接刻在序列上，留下四种可学习的印记：

  • 保守印记：必需蛋白的关键位置（催化位点、ATP 结合袋、结合界面）亿万年不许变，因此序列呈现极强的位置保守性；
  • 组成印记：膜通道蛋白富疏水残基、核酸结合蛋白富带电残基、金属酶富 Cys/His，氨基酸组成直接暴露功能类别；
  • 构造印记：跨膜段的数量与分布、无序区长度、结构域组合；"机器类"必需蛋白（聚合酶、核糖体、通道）有独特的构造规律；
  • 家族印记：非必需蛋白常是冗余家族成员或特化响应蛋白，序列呈现家族重复、弱保守、可变长度。

于是"这段序列所编码的蛋白是否在功能上不可缺失"是一个可统计的问题。模型学的是 序列特征 → 功能类别 → 不可替代性 → 必需性这条映射，全程只看序列，不看任何实验信息。

1.4 为什么模型对未见物种仍具预测能力：跨物种泛化的生物学基础

  • 同一套物理规则：所有生命共用同一套 20 种氨基酸、同一套折叠力、同一套生化反应。大肠杆菌和人细胞里的核糖体、DNA 聚合酶、ATP 合酶是"同一台机器的不同版本"：序列不同，构造原理相同。
  • 生存清单普适且核心极保守：DNA 复制/转录/翻译/基础能量代谢这份清单在演化上从细菌到人高度保守，核心必需组同源性极高[16]。同界之内（动物界内部、植物界内部）连"周边必需"（信号转导、运输、细胞器定位）都高度共享；这就是同界零样本最准的原因（枯草 0.7225），跨界递减（疟虫 0.5429）。
  • 模型学的是规律，不是名单：训练时模型只见各物种 A 源，从未记忆任何"物种与必需基因名单"。它学的是 1.3 节那条普适映射；新物种的序列进入，映射照常运转，这就是零样本（G3）的物理基础。
  • 诚实边界：零样本高度依赖"目标物种的标签口径与训练物种一致"。标签是推断的（衣藻 CLiP）、判据更严的（疟虫生长率阈值），数字随之下降；最弱结果不予正文列示。

1.5 8 座塔＋特征工程为什么能产生这样的预测能力

  • 塔＝演化级的功能阅读器：ESM2/T5 系模型[19][20]在数十亿条经演化筛选的自然序列上做"补全训练"，它们对"哪些位置受强烈进化约束"的编码是演化级的：一个位置的替换模式 ＝ 该位置受多大约束 ＝ 功能多核心。塔的深层向量等于把“这是哪类机器、哪些区段不可缺失”压缩为一段可计算的摘要。
  • 八塔集成＝多视角独立表征：不同架构（ESM2 vs T5）、不同容量（8M→3B）、不同语料的预训练模型读同一条序列各出一份"理解"，拼接后单模型偏置被稀释：有的塔擅长家族指纹，有的擅长远程残基关系，有的带结构通道（ESM3[21]）。
  • 冻结保证表征统一：塔参数全程不变，所有物种与数据集使用同一套嵌入，跨物种对比和零样本在方法论上才得以成立。
  • 特征工程＝透明的物理旁路：517 维手工统计[22]（疏水轮廓、二肽频次、CTD 排布、性质周期性、二级结构倾向、组成偏倚）把 1.3 节的四种印记直接量化，可解释可核查，是塔嵌入的互补与校验。
  • 头部校准：不同界的"必需组构成"有偏移（细菌核心必需几百个，真核几千个），specialist 头用物种上下文/逆频权重做校准；focal loss 让少数派正例（必需基因是少数）在训练中不被淹没[23]。

二、数据长什么样：X 和 Y 到底是什么

X（输入）= 蛋白序列的数值化向量，构造对所有数据集完全相同。每条氨基酸序列走两条并行管线： ① 8 座冻结蛋白质语言模型塔的嵌入拼接（320+480+640+1280+2560+1536+1024+768 = 8,608 维）； ② 7 组确定性统计视图（517 维，见 §6）。X 里没有任何实验信息，模型从序列本身学习该蛋白是否为生存所必需。

Y（标签）= 每个数据集各自的 0/1 列。1 = 该数据集的实验/判据认定必需；0 = 敲除后仍存活。Y 的判定实验随数据集而异，X 的构造在所有数据集中完全一致。

三、全数据集盘点（按物种）

下表按"三域六界 + 池外零样本"的总设计列出，古菌与原生生物分属两界，分节呈现。每个数据集标明：Y=1 的含义（什么技术破坏了基因、敲的是哪个物种、结果是什么，统一以"致死/无法存活"明确表述）→ 样本量 → 在战役里的角色。 角色代号：G1 训练 = 模型学习用的主菜池；G2 外测 = 同物种独立外部验证（零训练，只评测）； G3 零样本 = 池外未见物种，模型从未见过该物种任何数据。

G2 的标准形态是"同种跨源"：训练源 A 与外测集 B 是同一物种的两份独立数据，例如 IMPC→DEG（同为小鼠）、 SGD→DEG/sgd1017（同为酵母）、Keio→EDL933（同为大肠杆菌）、Lloyd2012→Meinke2019（同为拟南芥）、cell→wang2015/broad20q2（同为人类细胞系）。 各行的特殊口径（如古菌行）见表底小注。

六、特征工程：7 组确定性视图（517 维）的构造与生物学意义

"确定性" = 同一条序列永远算出同一组数字，无随机性、无模型参与，纯 CPU 统计。 视图名读自 code/_v4_round3_g2.py 第 45 行：physchem / kmer / ctd / autocorr / zscale / ss_prop / bias； 总维数 517（_DECISION_LOG_R24G3.json 的 views=zeros(n,517) 零样本约定为权威总维数在案值；各视图维数按项目特征注册表）。

视图算什么生物学意义
physchem（5）序列全局理化统计量疏水性/电荷等宏观物化轮廓，用以区分膜蛋白（疏水、跨膜区多）与水溶酶蛋白；必需蛋白里膜通道与转运体密集，这类轮廓直接相关
kmer（400）氨基酸短串（k-mer）频次统计（400 = 20×20，与二肽频次矩阵维度一致）二肽偏好反映蛋白家族与功能基团的特征性短串模式；酶活性位点周边、核糖体蛋白、转录因子各有标志性的短串分布
ctd（63）组成 C / 过渡 T / 分布 D 三族统计（按残基理化分组）不只数"有多少"，还数"怎么排"：带电残基是集中一端还是散布全长、疏水块的位置，可定位信号肽、跨膜段、核定位序列的关键模式
autocorr（20）物化性质沿序列位置的自相关统计性质的周期性/簇状性：结构域重复、螺旋-折叠交替等构造规律；必需的机器类蛋白（聚合酶、核糖体）常有强规律构造
zscale（5）氨基酸五维理化描述子（z1–z5）的序列聚合把 20 种氨基酸压成 5 个正交的物化轴（体积/疏水/极性/电性等）再统计，比单一理化指标更立体地刻画"该序列的整体理化特征"
ss_prop（6）二级结构倾向统计（螺旋/折叠/无规等）螺旋多的常是膜通道/结构骨架，折叠片富集的常是酶核心/β 桶；必需蛋白的构象类别分布存在系统性差异
bias（18）氨基酸组成偏倚统计相对背景组成的偏离：富含某类残基（如富 Lys/Arg 的核酸结合蛋白、富 Cys 的金属结合蛋白）是功能类别的强信号

与塔的关系。塔嵌入是"学出来的深层语义"，这 517 维是"手工的透明统计"。两者互补： 统计视图为可解释性锚点（审稿人能查），塔嵌入为表达力引擎。G2 的 specA 腿 = 8 塔+517d 一起上； G3 池外零样本按协议把视图置零（views=zeros），只留纯 backbone 零样本口径，即"模型从未见过该物种"的诚实版本。

七、实验纪律：为什么这些数字可信

  • 零训练红线（教授 10-18 铁律）：第二源（G2 的 B 侧）数据一律只评测、绝不参与任何形式的训练；涉转导的腿权重强制归零并披露（如 sgd1017 行）。
  • 选择与确认分离：所有配方在 A 侧交叉验证（OOF）上冻结后，B 侧只允许单发评测，杜绝"在测试集上调参"。
  • 判决只走闸门/生成器：WIN/LOSE 由预注册闸门计算生成，不许手改；LOSE 也是永久记录，重跑用新轮次号。
  • 切片守卫：full / s200（≤200 aa）/ s150（≤150 aa）三切片；任一切片 n<30 或正例<30 = 结构性不评（教授 2026-11-05 裁决：标注 "n=X(<30) 结构不评"，不出假精度数值）。
  • 诚实披露制：join 丢行（berghei 2,089→2,088）、推断标签（衣藻 CLiP 双口径）、纯正例集（Meinke κ 主报）、BLOCKED 不伪造（T. gondii 缺嵌入 bank），所有不对称信息均在判决文件中留痕。
  • 判决现状速览：小鼠 R19 WIN 0.8752 ＋ R21c WIN 0.8738（对 PIC 0.8736 双口径）；G2 七行 全 WIN（宪法 v2）；G3 零样本披露行在案；R25"多赢一点"边距战役进行中（M3 edl933 focal WIN 0.7439＞0.7323 单发入档）。

八、面向未来的挖掘：从训练完成的模型到生物发现

模型的预测能力本身并非终点；训练完成后，模型内部所习得的表征构成了进一步生物学挖掘的资产。本章以书面形式预先规划三个挖掘方向（当前均不启动），说明其做法、生物学意义与证据链。

8.1 必需性景观图：必需蛋白在序列空间中的全局组织

做法。将全部物种的蛋白通过冻结塔映射至 8,608 维表征空间，以模型输出的必需性分数对每个蛋白着色，并以降维投影（UMAP 或 PaCMAP）呈现二维景观。

需要检验的三个命题。其一，必需蛋白在景观中呈离散岛屿状分布（如核糖体岛、DNA 复制岛、膜机器岛），还是弥散分布：前者将说明"必需性"存在若干种不可互换的分子实现方式；其二，各界的必需蛋白是否共享同一片地形：若共享，则 G3 零样本成绩即从"经验结果"上升为"机制证据"（跨物种可迁移性的结构性解释）；其三，景观中必需岛边界上的过渡带蛋白即模型不确定性最高的区域，亦即湿实验验证优先级最高的候选清单，可构成主动学习式的实验闭环。

证据链。蛋白语言模型的表征空间已被证明在无监督条件下涌现功能结构[22][19]；本项目 G3 五物种零样本结果（枯草 0.7225 至疟虫 0.5429 的梯度）构成该景观"地形共享度"的初步观测点。

8.2 演化距离衰减曲线与界间转移矩阵：必需性的演化共享度

做法。以物种对之间的序列相似度（或系统发育距离）为横轴，以必需性标签的一致率（或模型迁移 AUROC）为纵轴，绘制"演化距离衰减曲线"；本项目 G3 数据即为该曲线上的现成观测点（近缘的同界物种对与远缘的跨界物种对）。进一步地，构造界间转移矩阵：以八个界的两两组合为格，量化各自必需蛋白组在表征空间中的重叠度（Jaccard 或 IoU）。

生物学意义。必需基因比非必需基因在演化上更为保守这一命题已有经典证据[36]；本项目的贡献在于将该命题从"序列保守性"推广至"功能不可替代性的跨物种共享度"，并以界间矩阵给出定量的"生存清单演化共享度"图谱。该图谱既可解释零样本迁移的成败（同界高、跨界低），也可指出哪些跨界方向值得投入新的实验数据。

8.3 疾病基因图谱：人类预测分数与 OMIM、DepMap 的对齐

做法。将模型对人类全基因组的必需性预测分数，与 OMIM 疾病基因目录[37]及 DepMap 癌症依赖图谱[10]按基因标识符对齐（join），构成四象限表格。本项目的差异化在于第三个维度：预测分数背后有跨物种演化证据（七个物种的实验必需性数据），这是单物种筛选资源所不具备的。

OMIM 有记载OMIM 无记载
我们预测必需（高分）交叉验证区：两个证据源均判定为核心基因，互为背书，模型可信度直接增强候选新疾病基因（见象限一）
我们预测非必需（低分）制药价值区（见象限二）双非核心：既无疾病记载，预测亦非必需，暂无挖掘价值

象限一（预测必需 × OMIM 无记载）。一个基因被模型判定为生存必需，却从未在任何患者家系中记载。可能的原因有两种：其致病突变导致胚胎期致死，个体无法存活至发病，因而不会进入以患者为入口的 OMIM 收录流程；或者该突变所致疾病尚未被识别为遗传病。两种情形下，该基因都是下一代疾病基因的首要候选，验证路径现成：CRISPR 敲除后观察胚胎干细胞的存活表型。DepMap 细胞系数据可提供第二重过滤：若该基因在癌细胞中同样必需，它还可能是合成致死治疗的靶点背景。

象限二（OMIM 有记载 × 预测非必需）。某基因已确认致病，但模型判定其缺失后机体仍可存活，意味着该基因大概率存在功能冗余或旁路通路（即 1.2 节不可替代性原理的反向应用）。这一判定对制药具有三重价值：其一，抑制该基因的毒性可能较低，因为正常细胞缺失后仍可存活；其二，病人对该基因的依赖是疾病状态特异的，这正是药物选择性的分子基础；其三，后续方向是确定该基因在何种条件下变得不可替代（例如仅在肿瘤代谢背景下必需），由此直接通往合成致死药物发现，PARP 抑制剂在 BRCA 突变肿瘤中的应用是该逻辑的经典先例[38]。

两个高价值象限。其一，模型预测必需而 OMIM 未记载的基因：OMIM 的收录以患者家系为来源，胚胎致死或幼年致死的基因缺乏先证者，构成 OMIM 的结构性盲区；模型的序列先验恰好不存在该盲区，因此该象限富集候选新疾病基因，可用 CRISPR 敲除直接验证。其二，OMIM 已记载而模型预测非必需的基因：依据不可替代性原理（1.2 节），该基因在正常生理下存在功能冗余，针对其的干预可能具有较低的正常组织毒性；若该冗余在疾病状态下被打破（如肿瘤代谢背景），即构成合成致死治疗窗口，PARP 抑制剂与 BRCA 突变肿瘤的关系[38]是该逻辑的经典先例。

证据链。OMIM 的收录机制以患者表型为入口[37]；DepMap 提供细胞系层面的实验必需性参照[10]；本模型的跨物种必需性先验与两者互补，三尺对齐后的象限落差即候选发现的结构性来源。
